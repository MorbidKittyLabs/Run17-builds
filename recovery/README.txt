MORBID KITTY — RUN17 R18 RECOVERY

This is a rollback utility for the broken controller build.

1. Extract the ZIP into a separate folder.
2. Open MorbidKitty-Recovery (the application).
3. If asked, choose Prime.exe for the affected game installation.
4. When recovery completes, start STFC using its usual game launcher.

Recovery stops the controller and closes the affected game client, then uses
the installer's recorded backups to restore the pre-installation files.
Other game installations are left running. Your actual game configuration
and saved panel settings are preserved. No account credentials are read.

If the installed DLL has since changed or a required backup is missing,
the utility stops rather than guessing which file should replace it.

This does not install new features or fix the withdrawn R18 controller.
