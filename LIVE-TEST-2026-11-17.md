Changes directly related to the report:
- Pixel-sized fonts and shared font lifetimes replace point fonts inside pixel
  bounds. Controller/timer text has a readable minimum size. The timer countdown
  column is wider. UI scale following remains.
- Windows voice inspection runs on bounded MTA workers. Native chat is requested
  before inspecting Windows microphone state; a slow provider does not stop UI.
- Store launch is independent of WMI discovery. Discovery and process launch run
  off the UI thread; cached verified process ownership scopes Store close.
- Window adjustments run on a bounded worker; game close no longer waits for
  synchronous window restoration. New game launches start borderless, with F9
  retaining the live windowed/borderless toggle.
- Right-drag is tracked outside the controller's original bounds while the game
  is a separate foreground process. No left clicks are consumed by that hook.
- Explicit user requests wait asynchronously for the game to actually receive
  foreground focus instead of rejecting an asynchronous focus change immediately.
- Dock lookup can locate live Unity FleetBarViewController instances and the
  native ShipBar canvas, independently of constructor tracking. It records masks
  and lookup failures in the game log without recording player/ship names.
